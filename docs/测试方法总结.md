## 🔑 关键要点

### 1. 数据划分一致性

**必须相同的参数**:
- `--seed 42`: 随机种子
- `--max_samples 2000`: 样本数限制
- `--test_ratio 0.15`: 测试集比例
- `--val_ratio 0.15`: 验证集比例

**可以不同的参数**:
- `--train_safe_ratio`: 训练集比例（这是要测试的）

### 2. 测试流程

```
1. 加载数据（max_samples限制）
   ↓
2. 划分数据（测试集/验证集/训练集）
   - 测试集和验证集：固定（相同seed）
   - 训练集：根据train_safe_ratio变化
   ↓
3. 提取隐藏态（使用LLM）
   ↓
4. 训练探针（每层独立）
   ↓
5. 保存结果和日志
```

### 3. 结果对比

**关键指标**:
- **通过层数**: 满足要求的层数
- **验证准确率**: 模型泛化能力
- **过拟合程度**: 训练准确率 - 验证准确率
- **数据利用率**: 使用的数据比例

**综合评分**:
```
评分 = 通过层数 × 10 + 验证准确率 × 100 - 过拟合程度 × 50
```

## 🎓 手动测试方法

如果不想使用测试脚本，可以手动测试：

### 测试1:1比例

```bash
python scripts/train_linear_probes.py \
    --use_optimized_split \
    --train_safe_ratio 1.0 \
    --max_samples 2000 \
    --test_ratio 0.15 \
    --val_ratio 0.15 \
    --num_epochs 20 \
    --seed 42 \
    --output_dir outputs/test_ratio_1.0
```

### 测试2:1比例

```bash
python scripts/train_linear_probes.py \
    --use_optimized_split \
    --train_safe_ratio 2.0 \
    --max_samples 2000 \
    --test_ratio 0.15 \
    --val_ratio 0.15 \
    --num_epochs 20 \
    --seed 42 \
    --output_dir outputs/test_ratio_2.0
```

**关键**: 必须使用相同的 `--seed` 和 `--max_samples`！

## 📈 结果解读

### 对比报告结构

1. **数据划分对比**: 不同比例下的数据分布
2. **训练结果对比**: 准确率、通过层数等指标
3. **详细分析**: 每比例的详细结果
4. **推荐**: 基于综合评分的最佳比例

### 选择标准

**最佳比例应该**:
- ✅ 通过层数多
- ✅ 验证准确率高
- ✅ 过拟合程度低
- ✅ 数据利用率高

---

## ⚠️ 注意事项

1. **GPU显存**: 如果显存不足，减小 `--batch_size` 和 `--probe_batch_size`
2. **训练时间**: 样本数和训练轮数直接影响训练时间
3. **数据一致性**: 必须使用相同的 `seed` 和 `max_samples`
4. **结果保存**: 每个比例的结果保存在独立目录

## 🔧 故障排除

### 问题1：GPU不可用

**检查**:
```bash
python -c "import torch; print(torch.cuda.is_available())"
```

**解决**: 使用CPU训练（速度较慢）

### 问题2：显存不足

**解决**: 减小批大小
```bash
python scripts/test_train_ratios.py \
    --batch_size 4 \
    --probe_batch_size 16
```

### 问题3：训练失败

**检查**:
- 数据文件是否存在
- 路径是否正确
- 参数是否有效
