# 探针训练逻辑说明

本文档说明当前探针训练的**整体流程、数据流、层内训练逻辑**及与主脚本的关系，便于理解与维护代码。

---

## 1. 整体流程概览

探针训练分为**数据→划分→特征→逐层训练→保存**五步，主入口为 `train_linear_probes.py` 或 `train_622_full.py`。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  1. 加载数据 (load_attack_enhanced)                                       │
│     base_evaluation.jsonl → texts, labels (0=安全, 1=有害)               │
└─────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  2. 数据划分 (split_data_* / split_data_optimized)                       │
│     → probe_train_texts/labels, probe_val_texts/labels, test_texts/labels│
│     可选：6:2:2 全训练、6:2:2 分层、按文档 6.5:1:1.5、优化划分等           │
└─────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 隐藏态提取 (extract_hidden_states)                                   │
│     文本 → LLM 前向 → 各层隐藏态 → 按非 padding token 做平均池化          │
│     输出：list of (num_layers, hidden_dim)  per 样本                     │
└─────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 逐层训练 (train_layer_probes)                                        │
│     对每一层：取该层隐藏态 → 训一个 LinearProbe(2 类) → 早停/重试 → 记 best │
│     详见下文「层内训练逻辑」                                               │
└─────────────────────────────────────────────────────────────────────────┘
                                      ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  5. 保存探针 (save_probes)                                               │
│     每层：probe.pt、toxic_vector.npz、metrics.json；按 filter_threshold 标记无效层 │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 2. 数据流与张量形状

| 阶段 | 变量 | 形状/含义 |
|------|------|-----------|
| 原始 | `texts`, `labels` | 文本列表，标签 0/1 列表 |
| 划分后 | `probe_train_texts/labels`, `probe_val_*`, `test_*` | 训练/验证/测试的文本与标签 |
| 提取后 | `hidden_states[i]` | 第 i 个样本的隐藏态，形状 `(num_layers, hidden_dim)` |
| 层内 | `train_layer_hs[j]` | 第 j 个训练样本在**当前层**的向量，形状 `(hidden_dim,)` |
| 训练 | DataLoader 的 batch | `hidden_states`: `(B, hidden_dim)`，`label`: `(B,)` |

**重要**：所有层共用**同一套**训练/验证样本与标签；每层只取**当前层的隐藏态**作为特征，因此「各层都有有害样本」等价于「划分后训练集里含有害样本」。

---

## 3. 层内训练逻辑（train_layer_probes）

### 3.1 输入与准备

- **hidden_states**：`List[np.ndarray]`，每个元素 `(num_layers, hidden_dim)`，对应一个训练样本。
- **labels**：与样本一一对应，0=安全，1=有害。
- **train_indices**：训练集下标（通常 `range(len(labels))` 表示全用当前划分出的训练集）。
- **val_hidden_states / val_labels**：验证集隐藏态与标签；若提供则优先于从 train 里再划 val。

对**当前层** `layer_idx`：

1. 取出该层特征：`train_layer_hs = [hs[layer_idx] for hs in train_hidden]`，验证集同理。
2. 构建 **HiddenStateDataset** + **DataLoader**（shuffle=True for train）。
3. 若 `use_class_weight=True`：按训练集统计算逆频率权重 `[w_safe, w_toxic]`，`CrossEntropyLoss(weight=...)`；否则不加权。

### 3.2 分层配置（get_layer_training_config）

每层有自己的：

- **num_epochs**：浅层略多（如 1.5×base），峰值层略多。
- **learning_rate**：浅层略大（如 1.5×base）。
- **dropout**：浅层小（如 0.05），中/深层略大（如 0.12），减轻过拟合。
- **min_required_acc**：0–5 层 0.76，6–14 层 0.85，15+ 层 0.90，第 28 层（峰值）0.93。

### 3.3 单层训练循环（epoch + 早停 + 重试）

```
while retry_count <= max_retries:
    新建 LinearProbe(dropout=layer_dropout)
    criterion = CrossEntropyLoss(weight=class_weight)  # 可选
    optimizer = AdamW(..., weight_decay=weight_decay)
    scheduler = ReduceLROnPlateau(mode='max', patience=5)
    (可选) 混合精度 use_amp

    for epoch in range(layer_epochs):
        # 训练
        for batch in train_loader:
            logits = probe(hs); loss = criterion(logits, label)
            loss.backward(); optimizer.step()
        # 验证
        val_acc, val_roc_auc, val_pr_auc = 在 val_loader 上算
        (若提供 test_loader) test_acc = 在 test_loader 上算
        scheduler.step(val_acc)
        training_history 记录本轮的 epochs/train_acc/val_acc/test_acc/train_loss/val_loss/lr

        if val_acc > best_val_acc_this_try:
            best_val_acc_this_try = val_acc
            best_probe_state_this_try = probe.state_dict()
            best_val_roc_auc_this_try = val_roc_auc
            best_val_pr_auc_this_try = val_pr_auc
            no_improve_count = 0
        else:
            no_improve_count += 1

        # 早停
        if 达标且 no_improve_count >= 6: break
        if no_improve_count >= 15: break   # 减轻过拟合

        if best_val_acc_this_try > best_val_acc:
            best_val_acc = best_val_acc_this_try
            best_probe_state = ...
            best_val_roc_auc = best_val_roc_auc_this_try
            best_val_pr_auc = best_val_pr_auc_this_try

    # 本 try 结束：若未达标且可重试，则 retry_count += 1，调大 lr/epochs、减小 dropout，继续 while
```

- **best_val_acc / best_probe_state**：层内全局最佳验证准确率及对应参数；**best_val_roc_auc / best_val_pr_auc** 为**达到 best_val_acc 那一轮**的 ROC-AUC / PR-AUC，写回该层的 `results[layer_idx]["metrics"]`。
- **早停**：达标且连续 6 轮无提升即停；或任意连续 15 轮无提升即停（减轻过拟合）。
- **重试**：若 `ensure_accuracy_requirements=True` 且本轮最佳 val_acc 仍低于 `min_required_acc`，最多重试 2 次，每次提高 lr、增加 epochs、减小 dropout。

### 3.4 本层结果

- 用 **best_probe_state** 覆盖当前 `probe`，再取 **毒性向量** `w_toxic, b = probe.get_toxic_vector()`。
- 写入 **results[layer_idx]**：`model`、`metrics`（含 `train_acc` 最后一轮训练准确率、`val_acc`/`val_roc_auc`/`val_pr_auc` 为达到 best_val_acc 那一轮的值、`min_required_acc`、`meets_requirement`）、`toxic_vector`、`training_history`（含每轮 `train_acc/val_acc/test_acc`、`train_loss/val_loss`、`learning_rate`）。

## 4. 与主脚本的关系

### 4.1 train_linear_probes.py

- 支持多种划分：`--use_optimized_split`（含 `--use_ratio_6_2_2`、`--use_doc_ratios`）、`--use_improved_split`、默认按文档 6.5:1:1.5。
- 若提供 `--hidden_states_cache`，则跳过加载 LLM 与提取，直接用缓存里的 `train_hs`/`train_labels`、`val_hs`/`val_labels`。
- 调用 `train_layer_probes(..., val_hidden_states=..., val_labels=..., ensure_accuracy_requirements=True)`，再 `save_probes(...)`。

### 4.2 train_test_1_5_1.py（当前测试脚本）

- **划分**：6:2:2 剩余全作训练集，训练集 **安全:有害=1.5:1**（固定）。
- **隐藏态**：对 train / val / **test** 均提取；训练时传入 `test_hidden_states`、`test_labels`，每轮记录 **test_acc**。
- **日志**（`outputs/probes_test_1_5_1/logs/`）：
  - **每层每轮**：`layer, epoch, train_acc, val_acc, test_acc, train_loss, val_loss` → `train_test_1_5_1_epochs_*.csv` / `.json`
  - **汇总**：`train_test_1_5_1_summary_*.json`（划分、超参、每层最终指标）
  - **每层详情**：`train_test_1_5_1_per_layer_*.json`（含完整 `training_history`，含每轮 val_acc/test_acc），便于后续计算与改进。

## 5. 已做的代码完善（与本逻辑相关）

1. **ROC/PR-AUC 的 if/else**：修正了「验证集仅单类时」的分支缩进，保证 `val_roc_auc`、`val_pr_auc` 在每种情况下都会赋值，且与「计算 ROC/PR-AUC」的 `if len(set(val_targets)) > 1` 成对。
2. **best 与 AUC 一致**：在更新全局 `best_val_acc` / `best_probe_state` 时，同步更新 `best_val_roc_auc`、`best_val_pr_auc`；写进 `results[layer_idx]["metrics"]` 的 roc/pr 为「达到 best_val_acc 那一轮」的 AUC，与保存的模型一致。
3. **类别权重**：`use_class_weight=True` 时按训练集逆频率构造 `[w_safe, w_toxic]`，并传给 `CrossEntropyLoss(weight=...)`，加强对少数类（有害）的学习。
4. **早停与过拟合**：达标后 6 轮无提升即停；任意 15 轮无提升即停；中/深层 dropout 提高至约 0.12；主脚本默认 `weight_decay=0.01`。

---

## 6. 小结

- **训练逻辑**：数据 → 划分 → 提隐藏态（平均池化）→ 对每一层用该层隐藏态训一个二类线性探针 → 早停/重试/类别权重/分层配置 → 保存最佳参数与毒性向量。
- **层与样本**：各层共用同一批训练/验证样本与标签，仅特征为「当前层隐藏态」不同。
- **结果含义**：每层的 `val_acc`、`val_roc_auc`、`val_pr_auc` 均对应**该层验证集上 best_val_acc 所在轮**的指标，与最终保存的 `probe` 和 `toxic_vector` 一致。
