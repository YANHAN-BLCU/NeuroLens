# NeuroLens 项目实验结果摘要

> 整理日期：2026-04-04 | 适用于：团队内部对接沟通

---

## 一、项目概述

NeuroLens 是一个基于 LLaMA 模型的大型语言模型可解释性研究项目，核心目标是：
1. **定位安全机制**：找出 LLaMA 模型中负责拒绝有害内容的神经元和层级
2. **提取毒性向量**：获取可指导安全干预的方向向量
3. **区分安全与有害神经元**：识别仅负责安全功能、不影响模型效用的专用神经元

## 三、模型输出（`outputs/`）

### 3.1 隐藏态提取（`outputs/hidden_states/`）

**含义**：将 LLaMA 模型对每个 prompt 生成的回复，在生成最后一个 token 时，各 Transformer 层的内部向量表示提取出来。

**数据规模**：

| 文件 | 样本数 | 存储大小 |
|------|--------|----------|
| `base_set_hidden_states_0_4999.hs.npy` | 5,000 | ~2.6 GB |
| `base_set_hidden_states_5000_9999.hs.npy` | 5,000 | ~2.6 GB |
| `base_set_hidden_states_10000_14999.hs.npy` | 5,000 | ~2.6 GB |
| `base_set_hidden_states_15000_21316.hs.npy` | 6,317 | ~3.3 GB |
| `attack_enhanced_hidden_states_0_4999.hs.npy` | 5,000 | ~2.6 GB |
| **合计** | **26,317** | **~13.7 GB** |

**文件格式**：
- `.hs.npy`：shape `(N, 32, 4096)`，float32
- `.idx.npy`：shape `(N,)`，记录每个隐藏态对应的 `original_index`
- `.jsonl`：每个隐藏态对应的生成文本

---

### 3.2 数据集输出（`outputs/data_set_output/`）

**含义**：LLaMA 模型对各 prompt 的生成回复 + 人工标注的安全标签。

**标签体系（三分类）**：

| 标签 | 定义 | 典型案例 |
|------|------|----------|
| **Safe** | 模型成功拒绝有害请求，生成安全回复 | "I cannot help with that" |
| **Unsafe** | 模型绕过安全机制，生成了有害/误导性内容 | 部分满足有害请求、提供虚假信息 |
| **Controversial** | 边界案例，模型回复模棱两可或涉及争议性话题 | 需专业判断的场景 |

**标签分布**：

| 数据集 | Safe | Unsafe | Controversial | Unsafe率 |
|--------|------|--------|--------------|---------|
| base_set（前3批） | 14,355 | 385 | 260 | ~2.4% |
| base_set（第4批） | 6,069 | 115 | 133 | 1.8% |
| attack_enhanced | 4,177 | 669 | 153 | **13.4%** |
| **合计** | **24,601** | **1,169** | **546** | **~4.4%** |

> **关键发现**：攻击增强集的 Unsafe 率（13.4%）远高于基础集（~2.4%），说明攻击模板能显著绕过安全机制。

### 3.3 线性探针训练（`outputs/linear_probes/`）

**含义**：在模型每层的隐藏态上训练一个线性分类器，检验该层对"安全/有害"二分类的判别能力。

**实验配置**：

| 参数 | 值 |
|------|-----|
| 分类器 | 单层线性层 `nn.Linear(4096, 2)` |
| 优化器 | AdamW（lr=1e-3, weight_decay=1e-4） |
| 学习率调度 | CosineAnnealingLR（T_max=100） |
| 训练轮数 | 100 epochs（保留最佳验证 epoch） |
| 验证策略 | 5折分层交叉验证 |
| 类别平衡 | Safe:Harmful 从 21:1 平衡采样至 1:1 |
| 最终样本量 | 2,338（Safe=1169, Harmful=1169） |

**各层性能总览（CV准确率）**：

| 等级 | 层级 | CV均值准确率 | 特征 |
|------|------|-------------|------|
| D级 | L01–L04 | 77.8%–82.9% | 波动大，语义信息不足 |
| C级 | L05–L09 | 83.7%–87.9% | 快速爬升期 |
| B级 | L10–L20 | 89.3%–92.0% | 稳定高性能 |
| A级 | L21–L26 | 91.7%–92.1% | Plateau 上半段 |
| **S级** | **L27–L32** | **92.5%–93.8%** | 最高准确率 |

**关键性能指标**：

| 指标 | 层级 | 数值 | 说明 |
|------|------|------|------|
| 最高 CV 准确率 | **L32** | **93.76%** | 信息整合最完整 |
| 最低 CV 标准差 | **L14** | **±0.48%** | 稳定性最优 |
| 首次突破 90% | L13 | 90.46% | 语义层成熟 |
| 首次完美平衡 | L10 | 89.31%=89.31% | Safe/Harmful 准确率一致 |

**层级推荐**：

| 场景 | 推荐层级 | 理由 |
|------|---------|------|
| 生产环境默认 | **L14 / L15 / L16** | 91.1–91.6% 准确率，标准差仅 ±0.48–0.82% |
| 追求最高准确率 | **L29 / L30 / L31** | 92.5–93.5% 准确率 |
| 轻量快速推理 | **L10** | 89.3%，仅为最佳层的 95.3% |

### 3.4 毒性向量（`outputs/toxicity_vectors/`）

**含义**：线性探针分类器权重的差值 `w_toxic = w[1] - w[0]`，代表从"安全"指向"有害"的方向向量。

**公式**：

```
P(y=toxic | h) = softmax(w_toxic · h + b)
w_toxic = w[1] - w[0]
```

**各层毒性向量 L2 范数趋势**：

| 阶段 | 层级 | L2范数 | 解读 |
|------|------|--------|------|
| 浅层 | L01 | 37.68 | 向量"发散"，区分度低 |
| 中层 | L15 | 17.43 | 中等紧凑 |
| 深层 | L28 | 12.06 | 精炼，区分度高 |
| 最深层 | **L32** | **3.78** | 向量最紧凑，准确率最高 |

> **规律**：L2 范数随层号递减，而准确率递增，说明深层毒性向量更"精炼"——少量调整即可区分安全/有害。

**层间相似度分析（Top 5）**：

| 排名 | 层对 | 余弦相似度 |
|------|------|------------|
| 1 | L23 ↔ L24 | 0.8802 |
| 2 | L22 ↔ L23 | 0.8663 |
| 3 | L24 ↔ L25 | 0.8471 |
| 4 | L25 ↔ L26 | 0.8347 |
| 5 | L18 ↔ L19 | 0.8283 |

> **规律**：L22–L26 和 L18–L19 相邻层高度相似，说明模型在深层对有害语义的编码方式相对稳定。

### 3.5 神经元分析（`outputs/neurons/`）

#### 3.5.1 专用安全神经元（`dedicated_safety_neurons.json`）

**含义**：从安全神经元中排除效用神经元后的结果，确保编辑这些神经元不会损害模型的一般任务能力。

**计算公式**：`D(p,q) = S(q) \ U(p)`

| 参数 | 值 | 含义 |
|------|-----|------|
| q | 0.5% | 安全神经元阈值（前0.5%的神经元构成 S(q)） |
| p | 0.1% | 效用神经元阈值（前0.1%的神经元构成 U(p)） |

**统计结果**：

| 指标 | 数值 |
|------|------|
| 安全神经元总数 | 655 |
| 效用神经元总数 | 131 |
| 重叠神经元 | 118 |
| **专用安全神经元** | **537** |
| 专用比例 | 81.98% |

**Top 10 专用安全神经元**：

| 排名 | 层号 | 神经元索引 | Score |
|------|------|-----------|-------|
| 1 | L31 | 4062 | 0.0590 |
| 2 | L31 | 788 | 0.0520 |
| 3 | L31 | 1384 | 0.0365 |
| ... | ... | ... | ... |
| 分布特征 | L31 > L1 > L30 > L21 > L17 | 高层显著富集 |

> **关键发现**：专用安全神经元在高层（L30–L31）显著富集，与线性探针结论一致。

#### 3.5.2 梯度依赖分析（`gradient_dependency/`）

**含义**：分析安全神经元激活与模型输出梯度之间的关系，用于理解安全机制的依赖路径。

#### 3.5.3 象限分类（`quadrant_classification.json`）

**含义**：将神经元按安全相关性和效用相关性划分为四个象限：
- Q1：高安全 + 高效用（双重功能）
- Q2：高安全 + 低效用（**专用安全神经元**，优先编辑目标）
- Q3：低安全 + 低效用
- Q4：低安全 + 高效用

#### 3.5.4 激活投影分析（`activation_projection.json`）

**含义**：将神经元激活投影到毒性向量方向，分析激活模式。

#### 3.5.5 参数对齐分析（`parameter_alignment.json`）

**含义**：分析安全神经元与模型参数结构的对齐程度。

## 四、核心结论

### 4.1 模型安全机制的层级分布

1. **LLaMA 的毒性表示随层数单调递增**，不存在"中间层最优"现象
2. **L32 是最佳单层选择**：CV 准确率 93.76%，标准差最低 ±0.66%
3. **L14 是最稳定的层级**：标准差仅 ±0.48%，适合生产环境
4. **L10 是分水岭**：首次突破 89%，Safe/Harmful 首次完美平衡

### 4.2 专用安全神经元

1. 发现 **537 个专用安全神经元**（占安全神经元的 81.98%）
2. 高层（L30–L31）显著富集专用安全神经元
3. 可通过编辑这些神经元实现安全干预，且不影响模型效用

### 4.3 攻击增强效果

1. 攻击增强集的 Unsafe 率（13.4%）是基础集（2.4%）的 **5.6 倍**
2. 说明现有安全机制可被越狱攻击显著绕过
3. 专用安全神经元编辑可能是更鲁棒的防御方向

## 五、注意事项与已知问题

1. **数据对齐**：所有数据通过 `original_index` 字段对齐，而非 JSONL 行号
2. **类别不平衡**：原始数据 Safe:Harmful ≈ 21:1，平衡采样后可能影响探针阈值
3. **轻微过拟合**：深层（L27–L32）验证损失约为训练损失的 1.5–2 倍
4. **idx.jsonl 不匹配**：约 2.1% 样本因数据格式问题被跳过，影响可控
