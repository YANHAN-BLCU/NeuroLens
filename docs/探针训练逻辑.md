## 理论基础

### 什么是线性探针（Linear Probe）？

线性探针是一种简单的线性分类器，用于分析预训练语言模型的内部表征。它通过在模型的隐藏状态上训练一个线性层，来识别特定语义信息（如有害内容）在模型中的分布。

### 数学公式

对于每一层的隐藏状态 $h \in \mathbb{R}^d$，线性探针使用以下公式进行分类：

$$P(\text{toxic} | h) = \text{softmax}(W^T h + b)$$

其中：
- $W \in \mathbb{R}^{d \times 2}$ 是权重矩阵（包含安全类和有害类的权重向量）
- $b \in \mathbb{R}^2$ 是偏置向量
- $w_{\text{toxic}} \in \mathbb{R}^d$ 是有害类别的权重向量（毒性向量）
- $b_{\text{toxic}}$ 是有害类别的偏置项

### 为什么使用最后 token 的隐藏状态？

- **上下文信息最丰富**：最后 token 的隐藏状态通常包含了整个序列的上下文信息
- **预测相关性强**：在生成任务中，最后 token 的隐藏状态与下一个 token 的预测最相关
- **通用实践**：这是线性探针研究中的标准做法

### 为什么需要分层训练？

- **语义分布不同**：有害语义在不同层中的分布可能不同
- **识别最佳层**：通过比较各层的性能，找出最能区分有害/安全内容的层
- **理解模型内部**：帮助理解模型在不同深度如何编码语义信息

```
原始数据 (base_evaluation.jsonl)
    ↓
【步骤1】数据加载与预处理

    │   ├── 提取该层的隐藏状态

【步骤6】保存结果

    ├── 保存每层的评估指标
    ├── 保存汇总信息
    └── 保存训练配置
```

## 详细训练逻辑

### 步骤1：数据加载与预处理

**代码位置**：`scripts/train_linear_probes.py` 的 `load_attack_enhanced` 函数

**详细流程**：

1. **读取 JSONL 文件**
   ```python
   for line in f:
       sample = json.loads(line)
   ```

2. **提取文本**
   - 从 `sample["input"]["prompt"]` 读取提示文本
   - 跳过空文本

3. **提取标签**（优先级顺序）
   - **优先**：`sample["guard"]["asr_label"]` (0=安全, 1=有害)
   - **其次**：`sample["guard"]["verdict"]`
     - `"allow"` → 0 (安全)
     - `"flag"` 或 `"block"` → 1 (有害)
   - 如果都无法判断，跳过该样本

4. **返回结果**
   - `texts`: 文本列表
   - `labels`: 标签列表 (0=安全, 1=有害)

**关键点**：
- 使用 Guard 的判定结果作为标签，更可靠
- 自动过滤无效样本

### 步骤2：数据划分

**代码位置**：`scripts/train_linear_probes.py` 的 `split_data_according_to_doc` 函数

**详细流程**：

#### 2.1 总体划分（80%:20%）

```python
# 随机打乱所有样本
indices = list(range(len(texts)))
rng.shuffle(indices)

# 划分测试集和训练集
test_size = int(len(indices) * 0.2)
test_indices = indices[:test_size]  # 前20%作为测试集
train_indices = indices[test_size:]  # 后80%作为训练集
```

**目的**：测试集完全隔离，不用于任何训练

#### 2.2 从训练集中划分（6.5:1:1.5 方案）

**探针训练集（72.2%，1:1 平衡）**：

```python
# 分离安全样本和有害样本
safe_indices = [i for i, label in enumerate(train_labels) if label == 0]
toxic_indices = [i for i, label in enumerate(train_labels) if label == 1]

# 计算每类可用的最大样本数
min_class_size = min(len(safe_indices), len(toxic_indices))
probe_train_per_class = min(min_class_size, probe_train_size // 2)

# 随机采样，确保1:1平衡
probe_train_safe_idx = safe_shuffled[:probe_train_per_class]
probe_train_toxic_idx = toxic_shuffled[:probe_train_toxic_idx]
probe_train_indices = probe_train_safe_idx + probe_train_toxic_idx
```

**为什么平衡到 1:1**：
- 防止模型偏向多数类（总是预测"安全"）
- 让探针必须学习区分两类样本

**探针验证集（11.1%，原始分布）**：

```python
# 从剩余数据中按原始比例采样
original_safe_ratio = num_safe / total_train
safe_val_size = int(probe_val_size * original_safe_ratio)
toxic_val_size = probe_val_size - safe_val_size
```

**为什么保持原始分布**：
- 真实场景中数据是不平衡的（82.3%:17.7%）
- 用原始分布验证，评估结果更真实

**输出**：
- `probe_train_texts`, `probe_train_labels`：探针训练集
- `probe_val_texts`, `probe_val_labels`：探针验证集
- `test_texts`, `test_labels`：测试集（隔离）

### 步骤4：提取隐藏状态

**代码位置**：`engine/probes/linear_probe.py` 的 `extract_hidden_states` 函数

**详细流程**：

#### 4.1 批处理文本

```python
for i in tqdm(range(0, len(texts), batch_size)):
    batch_texts = texts[i:i + batch_size]
```

#### 4.2 分词

```python
inputs = tokenizer(
    batch_texts,
    return_tensors="pt",
    padding=True,
    truncation=True,
    max_length=max_length,
).to(device)
```

#### 4.3 前向传播获取隐藏状态

```python
with torch.no_grad():
    outputs = model(
        **inputs,
        output_hidden_states=True,  # 关键：返回所有层的隐藏状态
        return_dict=True,
    )
```

#### 4.4 提取最后 token 的隐藏状态

```python
for b in range(batch_size_actual):
    seq_len = (inputs["attention_mask"][b] == 1).sum().item()
    last_token_idx = seq_len - 1
    
    # 提取每层最后token的隐藏状态
    layer_hidden_states = []
    for layer_idx, layer_hs in enumerate(hidden_states):
        last_token_hs = layer_hs[b, last_token_idx, :].cpu().numpy()
        layer_hidden_states.append(last_token_hs)
    
    # 堆叠为 (num_layers, hidden_dim)
    all_hidden_states.append(np.stack(layer_hidden_states))
```

**输出**：
- 每个样本的隐藏状态：`(num_layers, hidden_dim)` 的 numpy 数组
- 例如：32 层模型，隐藏维度 4096 → `(32, 4096)`

**关键点**：
- 使用 `attention_mask` 找到实际序列长度
- 只提取最后 token 的隐藏状态
- 转换为 numpy 数组以节省内存

### 步骤5：分层训练探针

**代码位置**：`engine/probes/linear_probe.py` 的 `train_layer_probes` 函数

#### 5.1 外层循环：遍历每一层

```python
for layer_idx in tqdm(range(num_layers), desc="训练层探针"):
    # 获取该层的训练配置（分层策略）
    layer_config = get_layer_training_config(layer_idx, num_layers, ...)
    # 对每一层训练一个独立的探针
```

**为什么需要循环**：
- 每一层都需要一个独立的探针模型
- 不同层的语义分布可能不同

**分层训练策略**：
- **浅层（0-5层）**：需要更多训练（75轮），更高学习率（3e-3），更少dropout（0.05），最低要求76%
- **中层（6-14层）**：标准配置（50轮，2e-3，0.1），最低要求85%
- **深层（15+层）**：减少dropout（0.08），最低要求90%
- **第28层**：特殊优化（60轮，2.2e-3，0.07），最低要求93%

#### 5.2 提取该层的隐藏状态

```python
# 从所有样本中提取该层的隐藏状态
train_layer_hs = [hs[layer_idx] for hs in train_hidden]
val_layer_hs = [hs[layer_idx] for hs in val_hidden]
```

**说明**：
- `hs` 的形状是 `(num_layers, hidden_dim)`
- `hs[layer_idx]` 是该层的隐藏状态，形状为 `(hidden_dim,)`

#### 5.3 创建数据集

```python
train_dataset = HiddenStateDataset(train_layer_hs, train_labels)
val_dataset = HiddenStateDataset(val_layer_hs, val_labels_list)

train_loader = DataLoader(
    train_dataset,
    batch_size=batch_size,
    shuffle=True,  # 训练集打乱

val_loader = DataLoader(
    val_dataset,
    batch_size=batch_size,

```

**HiddenStateDataset 的作用**：
- 将 numpy 数组转换为 PyTorch Tensor
- 支持 `__getitem__` 和 `__len__`，供 DataLoader 使用
- 优化：预转换为 Tensor，避免重复转换

#### 5.4 创建线性探针模型

```python
# 使用该层的配置（分层策略）
probe = LinearProbe(
    hidden_dim=hidden_dim,
    dropout=layer_dropout,  # 根据层索引调整（浅层0.05，深层0.08）

```

**分层配置说明**：
- 浅层使用更少的dropout（0.05），提高模型容量
- 深层使用标准dropout（0.08-0.1），防止过拟合

**LinearProbe 结构**：
```
输入: (batch_size, hidden_dim)
    ↓
Dropout (可选)
    ↓
Linear: (hidden_dim) → (2)
    ↓
输出: (batch_size, 2)  # [安全概率, 有害概率]
```

#### 5.5 定义损失函数和优化器

```python
criterion = nn.CrossEntropyLoss()  # 交叉熵损失
optimizer = torch.optim.Adam(
    probe.parameters(),
    lr=learning_rate,  # 默认 1e-3
    weight_decay=weight_decay,  # 默认 1e-2，L2正则化
)
```

#### 5.6 混合精度训练（服务器优化）

```python
use_amp = device.type == 'cuda' and hasattr(torch.cuda, 'amp')
scaler = torch.cuda.amp.GradScaler() if use_amp else None
```

**为什么使用混合精度**：
- 使用 FP16 计算，速度提升约 2 倍
- 显存占用减少约 50%
- 对精度影响很小

#### 5.7 训练循环（多个 epoch，带自动重训练）

```python
# 自动重训练机制：如果未达到要求，最多重试2次
max_retries = 2
retry_count = 0

while retry_count <= max_retries:
    for epoch in range(layer_epochs):  # 根据层索引调整轮数（浅层75轮，深层50轮）
    # 训练阶段
    probe.train()
    for batch in train_loader:
        hs = batch["hidden_states"].to(device, non_blocking=True)
        label = batch["label"].to(device, non_blocking=True)
        
        optimizer.zero_grad()
        
        # 混合精度训练
        if use_amp and scaler is not None:
            with torch.cuda.amp.autocast():
                logits = probe(hs)
                loss = criterion(logits, label)
            scaler.scale(loss).backward()
            scaler.step(optimizer)
            scaler.update()
        else:
            logits = probe(hs)
            loss = criterion(logits, label)
            loss.backward()
            optimizer.step()
        
        # 收集预测结果
        train_preds.extend(torch.argmax(logits, dim=-1).cpu().numpy())
        train_targets.extend(label.cpu().numpy())
    
    # 验证阶段
    probe.eval()
    with torch.no_grad():
        for batch in val_loader:
            hs = batch["hidden_states"].to(device)
            label = batch["label"].to(device)
            
            logits = probe(hs)
            probs = probe.predict_proba(hs)
            
            # 收集验证结果
            val_preds.extend(torch.argmax(logits, dim=-1).cpu().numpy())
            val_targets.extend(label.cpu().numpy())
            val_probs.extend(probs[:, 1].cpu().numpy())  # 有害类别的概率
```

**关键点**：
- `non_blocking=True`：异步数据传输，提高 GPU 利用率
- `torch.no_grad()`：验证时不计算梯度，节省内存和计算
- 保存最佳模型：根据验证集准确率选择最佳 epoch
- **早停机制**：如果达到要求且连续10轮无提升，提前停止训练
- **自动重训练**：如果未达到准确率要求，自动调整参数重试（最多2次）

#### 5.8 计算评估指标

```python
# 准确率
train_acc = accuracy_score(train_targets, train_preds)
val_acc = accuracy_score(val_targets, val_preds)

# ROC-AUC（需要正负样本都存在）

    val_roc_auc = roc_auc_score(val_targets, val_probs)
    
# PR-AUC（精确率-召回率曲线下面积）
precision, recall, _ = precision_recall_curve(val_targets, val_probs)
val_pr_auc = auc(recall, precision)
```

**指标说明**：
- **准确率 (Accuracy)**：正确预测的比例
- **ROC-AUC**：ROC 曲线下面积，衡量分类器区分能力（0.5=随机，1.0=完美）
- **PR-AUC**：精确率-召回率曲线下面积，更适合不平衡数据集

## 常见问题

### Q1: 训练时间太长怎么办？

**解决方案**：
1. 减少训练样本：使用 `--max_samples` 参数
2. 减少训练轮数：使用 `--num_epochs` 参数
3. 增大批大小：使用 `--probe_batch_size` 和 `--batch_size` 参数
4. 使用更强的 GPU

**示例**：
```bash
# 快速测试（100样本，5轮）
python scripts/train_linear_probes.py \
    --max_samples 100 \
    --num_epochs 5 \
    --probe_batch_size 64 \
    --batch_size 16
```

### Q2: 显存不足（OOM）怎么办？

**解决方案**：
1. 减小批大小：`--batch_size 4` 或 `--probe_batch_size 16`
2. 减小序列长度：`--max_length 256`
3. 使用梯度累积（需要修改代码）
4. 使用 CPU 训练（很慢，不推荐）

### Q3: 如何选择最佳层？

**方法**：
1. 查看 `summary.json`，找出 `val_roc_auc` 最高的层
2. 通常中间层（如第 15-20 层）性能最好
3. 综合考虑准确率和 AUC

**示例代码**：
```python
import json

with open("outputs/probes/probes/llama-3-8b/summary.json") as f:
    summary = json.load(f)

# 找出 ROC-AUC 最高的层
best_layer = max(
    summary["layers"].items(),
    key=lambda x: x[1]["val_roc_auc"]
)
print(f"最佳层: {best_layer[0]}, ROC-AUC: {best_layer[1]['val_roc_auc']}")
```

### Q4: 训练集和验证集准确率差距很大？

**可能原因**：
1. **过拟合**：模型在训练集上表现好，但验证集上差
   - 解决方案：增加 dropout、增加 weight_decay、减少训练轮数
2. **数据分布不同**：训练集是平衡的（1:1），验证集是不平衡的（82.3%:17.7%）
   - 这是正常的，验证集保持原始分布是为了更真实的评估

**判断标准**：
- 如果 `val_roc_auc` 和 `val_pr_auc` 都很高（>0.8），说明模型性能好
- 准确率差距大可能是因为类别不平衡，但 AUC 更能反映真实性能

## 性能优化建议

### 1. 隐藏状态提取优化

**当前实现**：
- 批处理提取，避免内存溢出
- 使用 `torch.no_grad()` 节省内存
- 转换为 numpy 数组节省显存

**进一步优化**：
- 如果显存充足，可以增大 `--batch_size`
- 使用多进程并行提取（需要修改代码）

### 2. 探针训练优化

**当前实现**：
- 混合精度训练（FP16）
- 异步数据传输（`non_blocking=True`）
- Dropout 正则化

**进一步优化**：
- 使用更大的批大小（如果显存允许）
- 使用学习率调度器（如 ReduceLROnPlateau）
- 早停（Early Stopping）机制

### 3. 内存优化

**建议**：
- 提取隐藏状态后，及时释放模型显存
- 使用 `del` 删除不需要的变量
- 定期调用 `torch.cuda.empty_cache()`
