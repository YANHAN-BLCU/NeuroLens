# 探针训练逻辑与操作步骤

## 一、训练逻辑详解

### 1.1 整体流程

```
┌─────────────────────────────────────────────────────────────┐
│ 步骤1: 数据加载与预处理                                        │
│ - 从 base_evaluation.jsonl 加载文本和标签                      │
│ - 使用 Guard 的 asr_label/verdict 自动标记（0=安全，1=有害）  │
│ 时间: ~1-5分钟（取决于数据量）                                 │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 步骤2: 数据划分（6.5:1:1.5方案）                              │
│ - 总体划分: 训练集(80%) + 测试集(20%)                          │
│ - 训练集划分: 探针训练集(72.2%, 1:1平衡) + 验证集(11.1%)       │
│ 时间: ~10-30秒                                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 步骤3: 模型加载（4-bit量化）                                   │
│ - 加载 Llama-3-8B 模型                                        │
│ - 自动使用 4-bit 量化（显存降低75%）                            │
│ 时间: ~2-5分钟（首次加载，后续可缓存）                          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 步骤4: 提取隐藏状态（平均池化）                                │
│ - 对训练集和验证集分别提取                                      │
│ - 使用平均池化，包含整个序列的信息                              │
│ - 输出: (num_layers, hidden_dim) 的numpy数组                  │
│ 时间: ~10-60分钟（取决于数据量和batch_size）                    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 步骤5: 训练分层探针（32层，每层独立训练）                       │
│ - 浅层(0-5): 75轮，要求76%                                     │
│ - 中层(6-14): 50轮，要求85%                                    │
│ - 深层(15+): 50轮，要求90%                                     │
│ - 第28层: 60轮，要求93%                                        │
│ 时间: ~30-120分钟（取决于数据量和epochs）                      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 步骤6: 保存探针与结果                                          │
│ - 保存每层的探针模型（.pt文件）                                 │
│ - 保存毒性向量（.npz文件）                                     │
│ - 保存训练指标和配置（.json文件）                               │
│ 时间: ~1-2分钟                                                │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 详细训练逻辑

#### 阶段1：数据准备

**代码位置**: `scripts/train_linear_probes.py:53-95`

1. **加载数据**:
   - 从 `base_evaluation.jsonl` 逐行读取
   - 提取 `input.prompt` 作为文本
   - 提取 `guard.asr_label` 或 `guard.verdict` 作为标签

2. **数据划分**:
   ```
   总数据 (100%)
   ├── 训练集 (80%)
   │   ├── 探针训练集 (72.2%, 1:1平衡) ← 用于训练探针
   │   ├── 探针验证集 (11.1%, 原始分布) ← 用于验证探针
   │   └── 神经元分析集 (16.7%) ← 预留
   └── 测试集 (20%) ← 完全隔离
   ```

3. **关键设计**:
   - 探针训练集1:1平衡：确保正负样本数量相等
   - 探针验证集保持原始分布：真实场景评估
   - 测试集完全隔离：不用于训练

#### 阶段2：模型加载

**代码位置**: `engine/models.py:268-370`

1. **自动检测GPU**:
   ```python
   if torch.cuda.is_available():
       device = torch.device("cuda:0")
   ```

2. **4-bit量化加载**:
   ```python
   quantization_config = BitsAndBytesConfig(
       load_in_4bit=True,
       bnb_4bit_compute_dtype=torch_dtype,
       bnb_4bit_use_double_quant=True,
       bnb_4bit_quant_type="nf4"
   )
   ```

3. **回退机制**:
   - 如果量化失败，自动回退到常规加载
   - 如果GPU显存不足，自动使用CPU

#### 阶段3：提取隐藏状态

**代码位置**: `engine/probes/linear_probe.py:207-280`

1. **批处理**:
   - 将文本分批处理（默认batch_size=8）
   - 每批进行分词和前向传播

2. **平均池化**:
   ```python
   # 获取有效token（排除padding）
   seq_len = (attention_mask[b] == 1).sum().item()
   sample_hs = layer_hs[b, :seq_len, :]  # 只取有效token
   
   # 平均池化
   pooled_hs = sample_hs.mean(dim=0)  # 对所有有效token求平均
   ```

3. **输出格式**:
   - 每个样本: `(num_layers, hidden_dim)` 的numpy数组
   - 例如: 32层模型，4096维 → `(32, 4096)`

#### 阶段4：训练分层探针

**代码位置**: `engine/probes/linear_probe.py:355-659`

1. **外层循环：遍历所有层** (32层)
   ```python
   for layer_idx in range(num_layers):  # 0-31
   ```

2. **获取层配置**:
   ```python
   if layer_idx < 6:
       epochs = 75, lr = 3e-3, min_acc = 76%  # 浅层
   elif layer_idx < 15:
       epochs = 50, lr = 2e-3, min_acc = 85%  # 中层
   elif layer_idx == 28:
       epochs = 60, lr = 2.2e-3, min_acc = 93%  # 峰值层
   else:
       epochs = 50, lr = 2e-3, min_acc = 90%  # 深层
   ```

3. **内层循环：训练每个epoch**:
   ```python
   for epoch in range(layer_epochs):  # 50-75轮
       # 训练阶段
       for batch in train_loader:
           # 前向传播、计算损失、反向传播
       
       # 验证阶段
       for batch in val_loader:
           # 计算验证准确率
       
       # 保存最佳模型
       if val_acc > best_val_acc:
           best_probe_state = probe.state_dict()
   ```

4. **重试机制**:
   - 如果未达到准确率要求，最多重试2次
   - 每次重试：学习率×1.2，轮数×1.2，dropout×0.8

5. **早停机制**:
   - 如果达到要求且连续10轮无提升，提前停止

#### 阶段5：保存结果

**代码位置**: `engine/probes/linear_probe.py:662-821`

1. **保存每层探针**:
   - 模型权重: `layer_{idx}/probe.pt`
   - 毒性向量: `layer_{idx}/toxic_vector.npz`
   - 训练指标: `layer_{idx}/metrics.json`
   - 训练历史: `layer_{idx}/training_history.json`

2. **保存汇总信息**:
   - `summary.json`: 所有层的准确率和有效性
   - `config.json`: 训练配置和数据统计
   - `training_log.json`: 完整的训练日志

3. **自动过滤**:
   - 准确率 < 75% 的浅层探针会被标记为无效
   - 但仍然保存，便于后续分析

### 2.2 方式一：完整训练（推荐用于首次运行）

**一次性完成所有步骤**：数据加载 → 模型加载 → 提取隐藏状态 → 训练探针

```bash
python scripts/train_linear_probes.py \
    --data_file data/salad/raw/base_evaluation.jsonl \
    --output_dir outputs/probes \
    --max_samples 4000 \
    --batch_size 8 \
    --max_length 512 \
    --num_epochs 50 \
    --probe_batch_size 32 \
    --lr 2e-3 \
    --weight_decay 1e-2 \
    --seed 42
```

**参数说明**:
- `--data_file`: 数据集路径
- `--output_dir`: 输出目录
- `--max_samples`: 最大样本数（None表示全量）
- `--batch_size`: 提取隐藏状态时的批大小（8-16，根据显存调整）
- `--max_length`: 分词最大长度（512）
- `--num_epochs`: 基础训练轮数（50，浅层会自动增加到75）
- `--probe_batch_size`: 探针训练批大小（32-64，根据显存调整）
- `--lr`: 学习率（2e-3）
- `--weight_decay`: 权重衰减（1e-2）
- `--seed`: 随机种子（42）

### 2.3 方式二：分步训练（推荐用于显存紧张或多次实验）

#### 步骤1：提取隐藏状态并保存

```bash
python scripts/extract_hidden_states.py \
    --data_file data/salad/raw/base_evaluation.jsonl \
    --max_samples 4000 \
    --seed 42 \
    --max_length 512 \
    --batch_size 8 \
    --output outputs/hidden_states_cache/base_evaluation_n4000_seed42_len512.npz
```

**输出**: `.npz` 文件，包含训练集和验证集的隐藏状态

#### 步骤2：使用缓存训练探针

```bash
python scripts/train_linear_probes.py \
    --hidden_states_cache outputs/hidden_states_cache/base_evaluation_n4000_seed42_len512.npz \
    --output_dir outputs/probes \
    --num_epochs 50 \
    --probe_batch_size 32 \
    --lr 2e-3 \
    --weight_decay 1e-2 \
    --seed 42
```

**优势**:
- 不需要重新加载模型
- 不需要重新提取隐藏状态
- 可以快速调整训练参数进行多次实验

### 3.3 分步训练的时间节省

**如果使用缓存（方式二）**:

| 步骤 | 完整训练 | 使用缓存 | 节省时间 |
|------|---------|---------|---------|
| 数据加载 | 1-2分钟 | 10秒 | 1-2分钟 |
| 模型加载 | 2-5分钟 | 0 | 2-5分钟 |
| 提取隐藏状态 | 15-30分钟 | 0 | 15-30分钟 |
| 训练探针 | 60-120分钟 | 60-120分钟 | 0 |
| **总计** | **80-159分钟** | **60-127分钟** | **18-37分钟** |

**优势**: 
- 可以多次调整训练参数，无需重新提取隐藏状态
- 如果训练失败，可以快速重新开始

### 3.4 影响时间的因素

1. **数据量**:
   - 样本数越多，时间越长
   - 提取隐藏状态时间与样本数线性相关
   - 训练探针时间与样本数线性相关

2. **batch_size**:
   - 提取隐藏状态: batch_size越大，时间越短（但显存占用越大）
   - 训练探针: batch_size越大，时间越短（但显存占用越大）

3. **epochs**:
   - 浅层(0-5): 75轮，时间最长
   - 中层(6-14): 50轮
   - 深层(15+): 50轮
   - 第28层: 60轮

4. **GPU性能**:
   - GPU越快，训练越快
   - 4-bit量化比常规加载快（显存占用小，可以增大batch_size）

5. **是否使用缓存**:
   - 使用缓存可以节省模型加载和隐藏状态提取的时间

### 3.5 时间优化建议

1. **首次运行**: 使用小规模数据（100-1000样本）测试
2. **正式训练**: 使用缓存方式，先提取隐藏状态，再多次训练
3. **调整参数**: 使用缓存可以快速调整训练参数
4. **增大batch_size**: 如果显存充足，增大batch_size可以加快训练
5. **减少epochs**: 如果时间紧张，可以减少epochs（但可能影响准确率）

## 五、常见问题

### 5.1 显存不足

**症状**: `RuntimeError: CUDA out of memory`

**解决方案**:
1. 减小 `--batch_size`（提取隐藏状态）
2. 减小 `--probe_batch_size`（训练探针）
3. 使用缓存方式，分步训练
4. 减小 `--max_samples`

### 5.2 训练时间过长

**解决方案**:
1. 使用缓存，避免重复提取隐藏状态
2. 减少 `--num_epochs`（但可能影响准确率）
3. 增大 `--batch_size` 和 `--probe_batch_size`（如果显存允许）
4. 使用更快的GPU

### 5.3 准确率不达标

**解决方案**:
1. 增加 `--num_epochs`
2. 调整 `--lr`（学习率）
3. 检查数据质量
4. 使用更多训练数据

## 六、总结

### 6.1 推荐流程

1. **首次运行**: 小规模测试（100样本，10 epochs）
2. **验证流程**: 中等规模（1000样本，50 epochs）
3. **正式训练**: 标准规模（4000样本，50 epochs）或全量数据
4. **多次实验**: 使用缓存方式，快速调整参数

### 6.2 时间规划

- **快速测试**: 10-20分钟
- **标准训练**: 1.5-2.5小时（4000样本）
- **全量训练**: 3-6小时（20000样本）

### 6.3 关键提示

- ✅ 使用缓存可以节省大量时间
- ✅ 先小规模测试，再正式训练
- ✅ 监控GPU使用情况，调整batch_size
- ✅ 保存训练日志，便于分析
