================================================================================
                    NeuroLens 项目
              开源代码与组件使用情况说明书
================================================================================

项目名称: NeuroLens
项目描述: 大语言模型安全神经元分析与可视化研究平台
版本: 1.0.1
更新日期: 2026年4月12日

================================================================================
第一部分 项目概述
================================================================================

NeuroLens 是实现 NeuroBreak 论文的完整研究管线，集神经元分析、可视化、
评估于一体的高级深度学习框架。项目采用模块化架构，由核心库(engine)、
研究脚本(scripts)和可视化系统(visualization)组成。

核心功能:
- 安全神经元识别与效用神经元检测
- SNIP 神经元重要性评分
- 激活投影与参数对齐分析
- 象限分类与专用安全神经元计算
- 线性探针训练
- 目标安全微调(TSFT/VA-TSFT)
- SALAD-Bench 越狱攻击评估
- 交互式数据可视化仪表盘(9个分析面板)

1.1 PyTorch
  版本: 2.6.0+cu124 (CUDA 12.4编译)
  官网: https://pytorch.org
  许可证: BSD License
  用途: 深度学习框架，提供张量计算、自动求导、神经网络模块
  关键模块:

【2】核心依赖关系链

数据流向:
  外部数据(SALAD、Utility)
    ↓
  [datasets] → 数据加载
    ↓
  [pandas + numpy] → 数据预处理
    ↓
  [transformers] → 模型加载与分词
    ↓
  [torch] → 前向传播、梯度计算
    ↓
  [sklearn] → 线性探针训练
    ↓
  [scipy] → 相似度/对齐计算
    ↓
  [numpy] → 神经元特征提取
    ↓
  结果保存
    ↓
  [fastapi + uvicorn] → 后端服务启动
    ↓
  前端访问 [react + echarts + plotly]
    ↓
  可视化展示

训练流向:
  [pytorch] → 微调框架
    ↓

第四部分 关键组件使用详解
================================================================================

【1】模型加载 (engine/models.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: transformers, bitsandbytes, modelscope (可选)

核心流程:
  1. 设置模型路径或 HF_TOKEN / MODELSCOPE_TOKEN
  2. 调用 AutoModelForCausalLM.from_pretrained()
  3. (可选) 加载 4-bit 量化配置
  4. 返回模型与分词器

模型支持:
  - 目标 LLM: Meta-Llama-3-8B-Instruct
  - 安全分类器: Llama-Guard-3-8B
  - 自定义模型: 任何 AutoModelForCausalLM 兼容的模型

【2】神经元分析 (engine/neurons/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: torch, numpy, sklearn, scipy

核心算法:
  - safety_identifier.py: 安全神经元识别 S(q)
    输入: 安全提示与回复
    输出: 按安全度排序的神经元列表

  - utility_identifier.py: 效用神经元识别 U(p)
    输入: 普通任务数据
    输出: 按激活度排序的神经元列表

  - snip_scorer.py: SNIP 重要性评分
    公式: I = |w ⊙ ∇L|
    用途: 离线选择关键神经元

  - activation_projection.py: 激活投影
    计算每层的激活向量 A_i^k
    用途: 跨层激活对比分析

  - parameter_alignment.py: 参数对齐
    计算参数变化一致性 S_i^k
    用途: 微调前后对齐评估

  - quadrant_classification.py: 象限分类
    分类维度: 安全性(S+/S-) × 激活度(A+/A-)
    结果: 4 个象限的神经元集合

【3】线性探针 (engine/probes/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: sklearn, numpy, torch

两个版本:
  - linear_probe.py: 基础版本
    使用 sklearn.linear_model.LogisticRegression

  - linear_probe_balanced.py: 平衡版本(推荐)
    使用 class_weight='balanced' 处理不均衡数据
    分层训练(每层一个探针)
    输出: 隐藏态中的有害语义表征

【4】微调框架 (engine/fine_tuning/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: torch, transformers, accelerate

两个方案:
  - TSFT (Target Safety Fine-Tuning)
    基础目标安全微调

  - VA-TSFT (Vulnerability-Aware TSFT)
    脆弱性感知微调
    额外考虑神经元脆弱性得分

微调流程:
  1. 初始化微调策略(目标神经元集合)
  2. 准备数据集(安全示例)
  3. 配置优化器与学习率(使用 Hydra)
  4. 训练循环(使用 Accelerate 加速)
  5. 保存增量权重(delta)

【5】评估系统 (engine/assessment/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: datasets, pandas, transformers

三个评估维度:
  1. ASR 评估 (Attack Success Rate)
     使用 SALAD-Bench 越狱数据集
     评估微调后的安全性改进

  2. Utility 评估
     使用 ARC、HellaSwag 等基准
     评估微调后的效用保持

  3. 报告生成
     统计分析与可视化
     输出 HTML/JSON 报告

【6】后端 API (visualization/backend/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: fastapi, uvicorn, pydantic, aiofiles

端口: 6008
功能:
  - /api/status: 获取任务状态
  - /api/neurons: 获取神经元分析结果
  - /api/submit_task: 提交新任务(管线、微调、评估)
  - /api/logs: 流式日志输出
  - 静态文件托管 (9个 HTML 面板)

【7】前端组件 (visualization/frontend/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

依赖库: react, echarts, plotly, zustand, axios

端口: 6006 (开发) / 6008 (生产)
技术栈:
  - 框架: React 18 + TypeScript
  - 路由: React Router
  - 状态: Zustand
  - 通信: Axios
  - UI 组件: Material-UI
  - 图表: ECharts + Plotly.js

9 个可视化面板:
  A - 控制面板: 任务提交、参数配置、实时日志
  B - 指标面板: ASR / Utility 核心指标雷达图

第八部分 重要事项与建议
================================================================================

【1】显存优化建议
  问题: 模型推理/训练 显存不足(OOM)
  解决方案:
    - 使用 bitsandbytes 4-bit 量化: 8B 模型 → ~5GB 显存
    - 启用梯度检查点: torch.utils.checkpoint.checkpoint()
    - 减小 batch_size
    - 使用 Accelerate 的自动混合精度(AMP)

【2】国内网络访问问题
  HuggingFace 下载速度慢:
    - 使用 ModelScope(阿里)替代: export MODELSCOPE_TOKEN=xxx
    - 手动下载后放入 ms_models/
  PyPI 包下载慢:
    - 配置清华 / 阿里镜像源

【3】配置与实验管理
  使用 Hydra 进行参数管理:
    - 配置文件: configs/runtime/*.yaml
    - 命令行覆盖: --learning_rate 1e-5 --batch_size 32
    - 多运行输出: outputs/年-月-日/时分秒/

【4】版本升级注意
  转换器 4.46 → 5.x 的兼容性问题:
    - API 变更: AutoModel.from_pretrained() 可能需调整
    - 模型权重格式: SafeTensors vs PyTorch
  建议: 暂不升级，保持 4.46.3

【5】数据隐私考虑
  SALAD-Bench 评估涉及越狱提示:
    - 仅用于学术研究
    - 不应用于对抗生成
    - 遵守 OpenSafetyLab 数据使用条款

【6】贡献代码规范
  代码检查流程:
    ```bash
    black .
    isort .
    ruff check .
    pytest
    ```
  提交前务必运行以上命令

================================================================================
结论
================================================================================

NeuroLens 项目通过整合 50+ 个开源库，实现了一套完整的大语言模型安全
神经元分析与可视化研究平台。核心依赖分为以下几个层级:

  1. 深度学习底层: PyTorch + Transformers (模型加载与计算)
  2. 数据处理层: NumPy + Pandas + SciPy (数据与统计)
  3. 算法层: Scikit-Learn (线性探针) + 自定义神经元算法
  4. 服务层: FastAPI + Uvicorn (Web API)
  5. 前端层: React + ECharts + Plotly (交互式可视化)
  6. 工具层: Hydra (配置) + pytest (测试) + Black/Ruff (代码质量)

所有依赖均为开源项目，主要采用 MIT、Apache 2.0、BSD 等宽松许可证，
确保学术研究和商业应用的灵活性。

项目的模块化设计使得研究人员可以独立调用各子模块(神经元分析、微调、
评估)，也可通过完整管线 run_neurobreak_pipeline.py 一键执行全流程。

后续维护与扩展建议:
  - 定期检查依赖更新(特别是 PyTorch/Transformers 主版本)
  - 监控 SALAD-Bench 数据集的最新版本
  - 考虑支持量化推理(GGML、TensorRT)以降低部署成本
  - 增强前端响应式设计以支持移动端预览
